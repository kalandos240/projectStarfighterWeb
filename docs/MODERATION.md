# Yandex Games moderation checklist — Project: Starfighter

This file separates checks that are enforced by the repository/CI from checks that can only be completed in a real Yandex Games Draft and Developer Console.

Upstream game: `pr-starfighter/starfighter` pinned at `315d0456723e19a153dbc5ef37d5cfb27b4cb36c`.

## Recommended Draft configuration

- **Supported platforms:** Desktop only. The current port is keyboard/mouse controlled. Do not declare Mobile until a complete gesture/touch control scheme has been implemented and tested.
- **Orientation:** landscape / default desktop presentation.
- **Game translated into:** Russian and English. Russian is supplied by the web translation table; English is the complete upstream source language. Automatic selection is based on `ysdk.environment.i18n.lang` before native UI creation.
- **Age rating:** **12+**. The game contains repeated space combat, lasers, missiles and explosions and story references to death/slavery, without realistic gore.
- **Cloud saves:** enable the “game uses cloud save” field. The port mirrors native Starfighter save slots to Yandex Player Data and also keeps an IDBFS local copy.
- **Monetization:** enable Yandex Advertising Network monetization if fullscreen ads are to be used.
- **AI declaration:** **AI was used partially**. AI assistance was used for porting code, QA, localization and project text; the original game and its upstream assets were not generated by AI.

## Mandatory real-Draft test before clicking “Send to moderation”

1. Upload the newest CI-generated `starfighter-yandexgames.zip` and save the Draft.
2. Set **Desktop only**, **12+**, Russian + English, and enable the cloud-save field. Enable YAN if ads are enabled.
3. Open **Draft with Debug Panel**. Confirm loader **IT** and Game Ready becomes green at actual readiness.
4. In SDK mocks select **ru** while the browser/portal may otherwise be English. Check title, main menu, difficulty, saves, system map, missions, upgrades/shop, options, mission briefing/objectives, pause screen, results/intermission and all buttons. Repeat with **en**.
5. Toggle Debug Panel focus off/on. Music and effects must stop while unfocused and resume afterward.
6. Watch the GameplayAPI/gamepad indicator: green only during actual mission gameplay; stopped in title/menu/intermission/pause/ad.
7. Create progress, save, reload, and verify the same save slot/progression returns. Then use “Clear cloud data” and verify clean first-run behavior.
8. Trigger a real fullscreen ad only after a mission/logical pause. Confirm game and audio remain paused while the ad is open.
9. Right-click inside the game canvas: no browser context menu. Resize the desktop browser through several aspect ratios: no important text/buttons may be cropped or overlap.
10. Inspect DevTools Console and Performance. There must be no functional JS/WASM errors, hangs, recurring long freezes or technical messages visible to the player.
11. Check all draft text/media: title identical everywhere; real gameplay screenshots; description/how-to-play match actual controls and content; no misleading or unrelated promotional art.
12. Search the current Yandex Games catalog for the exact title and closely matching versions immediately before submission.
